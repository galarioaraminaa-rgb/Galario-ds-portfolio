Laboratory Task 3 Forward and Backward Propagation

Name: Ara Galario
4th Year DS4A

Instruction: Perform forward and backward propagation in Python using the inputs from Laboratory Task 2. Use ReLU as the activation function and a learning rate of 0.001.

Setup¶

Row i of W1 holds the weights going into hidden neuron i, so W1 has shape (2, 3).

import numpy as np

x = np.array([1, 0, 1])
y = 1
lr = 0.001

W1 = np.array([[0.2, 0.4, -0.5],
               [-0.3, 0.1, 0.2]])
b1 = np.array([-0.4, 0.2])

W2 = np.array([-0.3, -0.2])
b2 = 0.1

def relu(z):
    return np.maximum(0, z)

1. Forward Propagation¶

z1 = W1 @ x + b1
h = relu(z1)
z2 = W2 @ h + b2
y_hat = relu(z2)

error = y_hat - y
loss = 0.5 * error**2

print("Hidden z:", z1)
print("Hidden h:", h)
print("Output z:", z2)
print("Prediction:", y_hat)
print("Error:", error)
print("Loss:", loss)

2. Backward Propagation¶

For E=12(y^−y)2E = \frac{1}{2}(\hat{y} - y)^2E=21​(y^​−y)2, the output delta is (y^−y)⋅f′(Z3)(\hat{y} - y) \cdot f'(Z_3)(y^​−y)⋅f′(Z3​). The delta is then passed back to the hidden layer using the output weights and the ReLU derivative (1 if z>0z > 0z>0, otherwise 0).

# output layer
delta_out = error * (z2 > 0)
dW2 = delta_out * h
db2 = delta_out

# hidden layer
delta_hidden = delta_out * W2 * (z1 > 0)
dW1 = np.outer(delta_hidden, x)
db1 = delta_hidden

print("Output delta:", delta_out)
print("Hidden delta:", delta_hidden)
print("dW2:", dW2)
print("db2:", db2)
print("dW1:\n", dW1)
print("db1:", db1)

3. Update Weights and Biases¶

wnew=w−η⋅∂E∂ww_{new} = w - \eta \cdot \frac{\partial E}{\partial w}wnew​=w−η⋅∂w∂E​

W1_new = W1 - lr * dW1
b1_new = b1 - lr * db1
W2_new = W2 - lr * dW2
