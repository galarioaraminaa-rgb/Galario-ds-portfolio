Conclusion¶

The confusion matrix gives a clearer picture of how well the model performs on each class by comparing the true labels with the predicted ones. It shows that the model identifies the majority class extremely well, correctly predicting 4,880 samples as class 0 and misclassifying only 3 of them as class 1. However, its performance noticeably drops when dealing with the minority class. Out of all the actual class 1 samples, the model incorrectly labels 76 of them as class 0, capturing only 41 correctly. This imbalance in performance highlights a common issue in datasets where one class dominates: even if the overall accuracy appears high, the model can still struggle to detect the rare class. The confusion matrix helps reveal this gap, showing that the model is reliable for class 0 but much less effective for class 1.hat accuracy is not a reliable metric for evaluating models trained on extremely imbalanced datasets.
