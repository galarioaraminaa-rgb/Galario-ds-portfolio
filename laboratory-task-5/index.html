Laboratory Task 5 PyTorch Basics

Name: Ara Galario
4th Year DS4A

This notebook completes Laboratory Task 5 from 02_PyTorch Basics.ipynb. Each step follows the task instructions and prints its result so it is easy to check.

1. Standard Imports¶

import numpy as np
import torch

print("NumPy:", np.__version__)
print("PyTorch:", torch.__version__)
NumPy: 2.1.3
PyTorch: 2.11.0+cpu

2. Create set_seed(seed)¶

The function seeds both NumPy and PyTorch and returns nothing.

def set_seed(seed):
    np.random.seed(seed)
    torch.manual_seed(seed)

3. Create NumPy Array arr¶

Six random integers from 0 (inclusive) to 5 (exclusive), using seed 42. The int32 dtype lets us convert to int64 in Task 5.

set_seed(42)

arr = np.random.randint(0, 5, 6).astype("int32")
print("arr =", arr)
print("dtype =", arr.dtype)
arr = [3 4 2 4 4 1]
dtype = int32

4. Create Tensor x from arr¶

x = torch.from_numpy(arr)
print(x)
print("dtype =", x.dtype)
tensor([3, 4, 2, 4, 4, 1], dtype=torch.int32)
dtype = torch.int32

5. Change x from int32 to int64¶

x = x.to(torch.int64)
print(x)
print("dtype =", x.dtype)
tensor([3, 4, 2, 4, 4, 1])
dtype = torch.int64

6. Reshape x into a 3 × 2 Tensor¶

x = x.reshape(3, 2)
print(x)
print("shape =", x.shape)
tensor([[3, 4],
        [2, 4],
        [4, 1]])
shape = torch.Size([3, 2])

7. Return the Right-Hand Column of x¶

print(x[:, 1])
tensor([4, 4, 1])

8. Return the Squares of x Without Changing x¶

x ** 2 creates a new tensor, so x stays the same.

print("Squared:")
print(x ** 2)

print("\nx is unchanged:")
print(x)
Squared:
tensor([[ 9, 16],
        [ 4, 16],
        [16,  1]])

x is unchanged:
tensor([[3, 4],
        [2, 4],
        [4, 1]])

9. Create Tensor y¶

x has shape (3, 2), so for matrix multiplication y needs 2 rows. With the same 6 elements as x, its shape is (2, 3).

torch.manual_seed(42)

y = torch.randint(0, 5, (2, 3))
print(y)
print("shape =", y.shape)
print("elements =", y.numel())
tensor([[2, 2, 1],
        [4, 1, 0]])
shape = torch.Size([2, 3])
elements = 6

10. Matrix Product of x and y¶

(3, 2) @ (2, 3) gives a (3, 3) result.

product = x @ y
print(product)
print("shape =", product.shape)
tensor([[22, 10,  3],
        [20,  8,  2],
        [12,  9,  4]])
shape = torch.Size([3, 3])

Final Check¶

  • NumPy and PyTorch imported

  • set_seed() created

  • seeded NumPy array created

  • array converted to a tensor

  • dtype changed to int64

  • tensor reshaped to 3 × 2

  • right-hand column extracted

  • squares returned without changing x

  • compatible (2, 3) tensor y created

  • matrix product computed
